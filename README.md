# Next Block

**One task. One block of focus.**

Next Block is a browser-based focus timer and task checklist. Pick a task, work for 25 minutes, then switch to a five-minute break.

## Try it

**[Open the live demo](https://codewithaditya-png.github.io/next-block/)**

To run it locally, download or clone this repository and open `index.html` in a browser. There is no build step.

- **Focus and break modes** offer 25- and 5-minute sessions with start, pause, resume, and reset controls.
- **Task checklist** lets you add, complete, and remove tasks.
- **Local storage** keeps your checklist in the same browser when supported. Reloading the page resets the timer.

## How it works

The app is a single HTML file. HTML gives the page structure, CSS adapts the layout for phones and desktops, and JavaScript runs the countdown and saves the checklist.

## First contribution

Try adding a longer focus option. Open an issue to describe the change, then use a branch and pull request to review it before merging.
